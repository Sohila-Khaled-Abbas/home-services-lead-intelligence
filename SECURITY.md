# Security Policy

## Supported versions

Security fixes are currently applied to the latest code on the \`main\` branch. There are no formal release branches yet.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the maintainer through the contact options on the [GitHub profile](https://github.com/Sohila-Khaled-Abbas).

Include, where possible:

- A concise description and potential impact.
- Affected file, commit, or version.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.

Do not include real customer data, private contact details, API credentials, tokens, or other secrets in a report.

## Secrets and extracted data

- Never commit API keys, passwords, access tokens, or local environment files.
- Review generated extraction output before publishing it.
- Treat third-party contact details as data requiring source, license, and purpose review.
- Report accidental disclosure promptly and avoid copying the exposed material elsewhere.
